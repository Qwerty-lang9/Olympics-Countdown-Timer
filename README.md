# 🏅 Olympics Countdown Timer

A simple **Olympics 2028 Countdown Timer** built using **HTML and JavaScript**.

The timer calculates and displays the remaining **Days, Hours, Minutes, and Seconds** until the 2028 Olympic Games and updates every second.

---

##  Features

- ⏳ Live countdown to the 2028 Olympics
- 📅 Displays Days, Hours, Minutes, and Seconds
- ⚡ Updates automatically every second
- 🖥️ Beginner-friendly JavaScript project

---

## 🛠️ Technologies Used

- HTML5
- JavaScript (ES6)

---

##  Concepts Practiced

- DOM Manipulation
- JavaScript Date Object
- Time Calculations
- Math.floor()
- Modulo Operator (`%`)
- setInterval()
- padStart()
